# Прогноз повітряних тривог по районах

Ймовірність того, що в районі **почнеться нова** повітряна тривога протягом 1, 3 або 6 годин.

> Це статистичний прогноз, а не офіційне оповіщення і не гарантія безпеки.
> Орієнтуйтесь на офіційні сигнали.

Детально: [reports/model_report.md](reports/model_report.md) (модель, метрики, сервіс, невирішене),
[reports/data_assumptions.md](reports/data_assumptions.md) (дані та припущення).

## Встановлення

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписати ALERTS_IN_UA_TOKEN
```

## Живі дані

Джерело — API alerts.in.ua (`ALERT_SOURCE=alerts_in_ua`). Дані пишуться в `data/live/alerts.sqlite`.

```bash
.venv/bin/python scripts/archive_alerts.py           # знімок історії за 30 діб (~14 хв, ліміт API)
.venv/bin/python scripts/live_poll.py --import-archive
.venv/bin/python scripts/live_poll.py --interval 90  # опитування активних тривог
.venv/bin/python scripts/live_poll.py --reconcile    # точні кінці тривог з історії
```

- Тривога, що зникла з відповіді API, закривається моментом опитування (наближено).
  `--reconcile` або свіжий знімок історії замінюють цей момент точним кінцем.
- Історія в API доступна лише за 30 діб. `archive_alerts.py` треба запускати регулярно, інакше в
  архіві з'явиться діра.
- Офіційне API (api.ukrainealarm.com) передбачене як `ALERT_SOURCE=ukrainealarm`, але ключа немає,
  тому воно не реалізоване.

## predict()

```python
import pandas as pd
from src.service import predict, live_forecaster

now = pd.Timestamp.now(tz="UTC")

predict("Харківська область|Харківський район")      # -> {1: p, 3: p, 6: p} на зараз
fc = live_forecaster()
fc.forecast("м. Київ", now)    # + чи тривога активна, яка модель, вік даних, stale
fc.list_regions()              # 105 одиниць: "Область|Район" або "Область|*"
```

Регіон задається як `Область|Район`. Для м. Київ, Запорізької й Тернопільської областей можна
вказати просто назву області: їхні райони в даних ідентичні, тож це одна одиниця.

## Яка модель для яких областей

| Області | Модель | Чому |
|---|---|---|
| Волинська, Рівненська, Львівська, Тернопільська, Івано-Франківська, Закарпатська, Чернівецька | **клімат**: частота за (район × година тижня) | GBM тут не переміг клімат: тривог мало, режим змінюється між сезонами |
| решта 16 (вкл. м. Київ) | **GBM**, калібрований на validation | на test Brier skill відносно клімату 0.09–0.15 (95% CI не перетинає 0) |
| Донецька, Луганська, АР Крим, Севастополь | прогнозу немає | постійна тривога / окупація / райони не розрізняються |

Якщо тривога вже активна, ймовірність на 1 год зазвичай низька: нова тривога можлива лише після
відбою.

## Що не покриває зовнішня перевірка

Зовнішня перевірка — 22.09–15.10.2026, дані alerts.in.ua. Вона **не є** test і не означає, що
модель перевірена на живих даних:

- **Інше визначення тривоги.** Модель вчилася на офіційному каналі (лише «повітряна тривога»), а
  alerts.in.ua містить ще й «попередню загрозу» (жовтий рівень, ~68% записів). Точної відповідності
  рівнів не встановлено.
- **Відтворення живого режиму.** Перевірку побудовано з історії з точними кінцями тривог. Наближені
  кінці з опитувань і можливі пропуски полера вона не відтворює.
- **Період 29.08–22.09.2026.** Даних районного рівня тут немає (діра й 7-денний розігрів ознак).
- **Офіційні дані після 28.08.2026.** Офіційний канал мовчить з 07.09, тож якість на офіційному
  визначенні після test невідома.
- **Рішення щодо заходу.** Його ухвалено після двох переглядів test; зовнішня перевірка його не
  підтверджує, бо там інше визначення тривоги.
